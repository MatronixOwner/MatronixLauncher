ЕСТЬ ВОПРОСЫ?

Коротко
об основном.

Важная информация об установщике и возможностях лаунчера.

Для какой системы есть установщик?

Сейчас на сайте размещён установщик для Windows. Пакеты для других систем не заявлены.

Какие аккаунты поддерживаются?

Вход в лаунчере поддерживает Ely.by. Не отправляй пароли и секреты аккаунта в обращения поддержки.

Откуда загружаются моды?

Каталог и загрузка модов используют Modrinth — другие источники модов лаунчер не использует.

Почему Windows предупреждает об установщике?

Текущий установщик не подписан сертификатом издателя. Скачивай его только со страницы официального GitHub Releases. Такое предупреждение не является проверкой безопасности файла.

Лаунчер включает Minecraft?

Нет. Установщик лаунчера не содержит Minecraft. Для доступа к игре и аккаунту действуют условия соответствующих сервисов.

Нашёл ошибку?

Напиши о ней в GitHub Issues. Не прикладывай пароли, токены и личные данные.
