Помощь и поддержка

Частые вопросы.

Короткие ответы про установку, аккаунт и моды.

Для каких систем есть установщик?

Сейчас на сайте опубликован установщик для Windows. Пакеты для других операционных систем здесь не заявлены.

Какие аккаунты поддерживаются?

Вход в лаунчере поддерживает Ely.by. Не отправляй пароль или секреты аккаунта в обращениях поддержки; авторизуйся только в окне входа самого лаунчера или на официальном сайте сервиса.

Откуда загружаются моды?

Каталог и загрузка модов в MatronixPrismLauncher используют Modrinth. Другие источники модов лаунчер не использует.

Windows показывает предупреждение при запуске установщика — что делать?

Текущий установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. Скачивай его только со страницы официального GitHub Releases. Само предупреждение не является проверкой безопасности файла — всегда проверяй, что ссылка ведёт на репозиторий MatronixOwner.

Лаунчер включает саму игру?

Нет. Установщик лаунчера не содержит Minecraft. Для доступа к игре и аккаунту действуют условия соответствующих сервисов.

Не нашли ответ?
