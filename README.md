# MatronixLauncher

Прототип лаунчера Minecraft с минималистичным чёрным интерфейсом, деликатной анимацией и неоновыми акцентами; выбором Vanilla / Fabric / Forge, поиском в Modrinth и CurseForge и локальным помощником по лаунчеру. Помощник отвечает по встроенным подсказкам и не отправляет вопросы в облако.

## Установка и запуск из исходников

```bash
npm ci
npm run dev                 # веб-просмотр
npm run desktop             # Electron (при запущенном dev-сервере)
npm run build               # веб-сборка
npm run dist:win             # portable EXE
npm run dist:win:installer   # NSIS-мастер установки для Windows
```

Установщик NSIS позволяет выбрать язык и папку, создаёт пункты меню «Пуск» и ярлык на рабочем столе. Значок приложения берётся из `build/icon.ico`, подготовленного из присланной эмблемы.

## Статус

Это ранняя версия оболочки, не полноценный игровой лаунчер. Minecraft пока не скачивается и не запускается; Microsoft-вход, автоматическая установка версий и загрузчиков, а также реальная установка модов ещё не сделаны. Поиск Modrinth использует официальный API, CurseForge требует пользовательский API-ключ. Работа сторонних сервисов зависит от региона и сети, поэтому доступность во всех странах гарантировать нельзя.

## Windows-сборки и релизы

GitHub Actions собирает установщик при каждом push в рабочую ветку и прикрепляет EXE как временный workflow artifact. Релиз с установщиком публикуется при push тега `v*` или при ручном запуске workflow с опцией публикации.
