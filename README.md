# MatronixLauncher

Настольный лаунчер Minecraft с каталогом версий из официального манифеста Mojang: релизы, снапшоты, бета и альфа. Vanilla-версии устанавливаются с официальных источников игры и Java runtime. Для авторизации используется Ely.by; лаунчер отправляет пароль только на `authserver.ely.by` по HTTPS, не сохраняет его и хранит токен сессии в системном шифрованном хранилище Electron, когда оно доступно.

Для профиля Ely.by устанавливается официальный `authlib-injector` с проверкой SHA-256, чтобы Minecraft использовал серверы авторизации Ely.by. Доступен и локальный офлайн-профиль с ником: он не входит в Ely.by, не скачивает Minecraft или Java и не позволяет обойти онлайн-проверку на серверах. Офлайн-запуск возможен только если выбранная версия полностью установлена локально вместе со всеми файлами и Java; для первой/незавершённой установки подключись к интернету и запусти установку через Ely.by. Фактическая установка модов и загрузчиков Fabric/Forge пока не подключена. Поиск Modrinth и CurseForge доступен в интерфейсе (для CurseForge нужен API-ключ); работа внешних сервисов зависит от сети и региона. Встроенный помощник использует локальные подсказки, а не облачную нейросеть.

## Установка и запуск из исходников

```bash
npm ci
npm run dev                 # веб-просмотр интерфейса
npm run desktop             # Electron (при запущенном dev-сервере)
npm run build               # веб-сборка
npm run dist:win             # portable EXE
npm run dist:win:installer   # NSIS-мастер установки для Windows
```

Сначала нажми «Установить»: лаунчер загрузит и подготовит выбранную версию Minecraft, библиотеки, ассеты, подходящий официальный Java runtime и (для Ely.by) authlib-injector. После успешной установки появится кнопка «Играть»; сам запуск не занимается установкой игровых файлов. Для игровых ассетов есть резервный BMCLAPI-источник; файлы сверяются с SHA-1 из официального манифеста Mojang. Повреждённые копии удаляются, а загрузки повторяются при временных сбоях. В офлайн-профиле вместо установки доступна только проверка уже установленных файлов — она не может восстановить прерванную загрузку.

## Windows-сборки и релизы

GitHub Actions собирает Windows-установщик при push в рабочую ветку и сохраняет EXE как workflow artifact. Публикация GitHub Release выполняется при push тега `v*` либо вручную через workflow.
