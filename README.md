# ElyPrism Launcher

Первый рабочий прототип интерфейса лаунчера Minecraft: тёмная кастомизируемая оболочка, выбор Vanilla / Fabric / Forge, каталог Modrinth, интеграция CurseForge через личный API-ключ и Electron-упаковка под Windows.

## Запуск интерфейса и приложения

```bash
npm install
npm run dev       # веб-просмотр интерфейса
npm run desktop   # Electron-приложение (после запуска dev-сервера)
npm run build     # собрать веб-интерфейс в dist/
npm run dist:win  # собрать portable ElyPrism-Launcher-0.1.0-win-x64.exe
```

NSIS-установщик вместо portable EXE: `npm run dist:win:installer` (может требовать Windows или Wine).

## Текущий статус

Это начальная оболочка, а не готовый игровой лаунчер: кнопка «Играть» честно сообщает, что движок пока не подключён; выбор версии/загрузчика пока меняет профиль интерфейса, но ещё не скачивает и не устанавливает Minecraft. Кнопки установки модов — прототип очереди, они ещё не загружают файлы. Поиск Modrinth обращается напрямую к официальному API; CurseForge требует пользовательский API-ключ и может быть недоступен из отдельных сетей или регионов. Ни один лаунчер не может гарантировать доступность внешних сервисов во всех странах.

Следующий этап — отдельная реализация игрового ядра: менеджер версий и библиотек Minecraft, авторизация Microsoft, скачивание и запуск Java, безопасная установка профилей Fabric/Forge и установка модов с проверкой совместимости и лицензий.
