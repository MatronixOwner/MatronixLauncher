# MatronixLauncher

Настольный лаунчер Minecraft с каталогом версий из официального манифеста Mojang: релизы, снапшоты, бета и альфа. Vanilla-версии можно установить и запустить с официальными файлами игры и Java runtime. Для входа используется Microsoft OAuth; требуется аккаунт с лицензией Minecraft Java Edition.

В интерфейсе также есть поиск Modrinth и CurseForge (для CurseForge нужен API-ключ). Фактическая установка модов и загрузчиков Fabric/Forge пока не подключена. Работа внешних сервисов зависит от сети и региона, поэтому их доступность везде не гарантируется. Встроенный помощник использует локальные подсказки, а не облачную нейросеть.

## Установка и запуск из исходников

```bash
npm ci
npm run dev                 # веб-просмотр интерфейса
npm run desktop             # Electron (при запущенном dev-сервере)
npm run build               # веб-сборка
npm run dist:win             # portable EXE
npm run dist:win:installer   # NSIS-мастер установки для Windows
```

Первый запуск игры может занять время: лаунчер скачает нужную версию Minecraft, её библиотеки, ассеты и подходящий официальный Java runtime. Учётные данные Microsoft обрабатываются через OAuth; пароль Microsoft лаунчер не запрашивает. Токен обновления, если системное хранилище Electron доступно, сохраняется локально в зашифрованном виде.

## Windows-сборки и релизы

GitHub Actions собирает Windows-установщик при push в рабочую ветку и сохраняет EXE как workflow artifact. Публикация GitHub Release выполняется при push тега `v*` либо вручную через workflow.
